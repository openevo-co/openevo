## The Engine (V1 Architecture)

OpenEvo is built on a lightweight, dependency-free **5-Phase Engine Loop**:

1. **PULSE EVALUATION** — Checks the internal biological clock (`pulse.md`) to determine if a proactive action or conversation initiation is required.
2. **RULE INJECTION** — Loads the 6-Layer Persona (`soul.md`, `role.md`, `character.md`, `user.md`, `rule.md`, `pulse.md`) to establish sovereign identity.
3. **MEMORY RECALL** — Queries local vector memory (RAG) to maintain conversational continuity.
4. **API DISPATCH** — Streams the payload to your chosen LLM (OpenRouter, Ollama, OpenAI).
5. **MEMORY MUTATION** — Stores both user intent and bot response locally for future context.

### 🫀 Proactive AI (The Pulse)
Unlike traditional reactive chatbots, OpenEvo introduces **The Pulse** (`pulse.md`). This 6th layer acts as an internal biological clock and situational awareness tracker, allowing Alive Bots to initiate conversations, understand the passage of time, and adapt their mood dynamically.


## 🚀 Quick Start

1. **Install OpenEvo Engine**

   **🍏 macOS / 🐧 Linux / WSL**
   ```bash
   curl -fsSL https://openevo.co/install | bash
   ```

   **🖥️ Windows (PowerShell)**
   ```powershell
   irm https://openevo.co/install.ps1 | iex
   ```

2. **Initialize your Sovereign AI**
   ```bash
   npx create-openevo my-bot
   ```

3. **Configure & Run**
   Edit your `config.yaml` to specify the LLM Provider and Model, then run your bot:
   ```bash
   npm run dev
   ```
